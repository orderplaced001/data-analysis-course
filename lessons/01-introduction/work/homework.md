## H3. Инструменты

Series и DataFrame, пример: Series — это один столбец данных с индексом, а DataFrame —
таблица, состоящая из нескольких таких столбцов. В работе home_decisions — это
DataFrame (6830 строк и 7 столбцов), а home_outcomes = home_decisions["action_taken"] —
Series, один столбец с кодами исходов.

nrows и head, пример: nrows — это параметр функции read_csv. Он указывает, сколько
первых строк файла прочитать, поэтому остальной файл вообще не загружается, например
pd.read_csv("decisions.csv", nrows=5). head — это метод уже загруженной таблицы: она
целиком находится в памяти, а head() только показывает первые строки, например
home_decisions.head(). То есть nrows ограничивает чтение, а head ограничивает показ.

Метод и атрибут, пример: метод — это действие, которое объект выполняет, его вызывают
со скобками, например home_outcomes.eq(3) сравнивает каждое значение с 3, а
home_outcomes.isin([1, 2]) проверяет принадлежность списку. Атрибут — это готовое
свойство объекта, его пишут без скобок, например home_decisions.shape показывает
размер таблицы (6830, 7).

Ссылка на документацию и что удалось уточнить:
https://pandas.pydata.org/docs/reference/api/pandas.Series.isin.html
В документации метода Series.isin описан параметр values, то есть набор значений,
с которыми сравнивается столбец (в работе это список [1, 2]). Результат — Series из
True и False той же длины, поэтому sum() считает количество подходящих записей.

## H+2. Типы значений — необязательно

Выполнялось: да.

Результаты сравнений для столбца action_taken из reading_example.csv, прочитанного как
строка: eq(1) дало [False, False, False, False, False, False], количество True = 0;
eq("1") дало [True, True, False, False, False, False], количество True = 2.

Объяснение: столбец считан как строка, значения в нём "1", "2", "3". Число 1 и текст "1"
для pandas разные значения, поэтому сравнение с числом ни с чем не совпало. Типу
прочитанного столбца соответствует сравнение со строкой, то есть eq("1").
